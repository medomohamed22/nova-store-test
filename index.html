الملفات والمعاينة
لا يوجد ملف محدد
معاينة حيّة ومعزولة لملفات HTML و CSS و JavaScript. يتم تحديثها تلقائياً أثناء تعديل الملفات.
أدوات ملفات محلية بأسلوب وكلاء البرمجة مثل OpenCode/Hermes. ينفذ AiWay أوامرها داخل مساحة العمل الحالية فقط.
list_files

عرض أسماء ملفات المشروع الحالية.

read_file

قراءة محتوى ملف موجود قبل تعديله.

create_file / write_file

إنشاء ملف جديد أو كتابة محتوى كامل داخل ملف.

edit_file

تعديل جزء محدد باستخدام old_text و new_text بدلاً من إعادة الملف كاملاً.

delete_file

حذف ملف من مساحة العمل الحالية.

preview

فتح تبويب المعاينة وتشغيل index.html مع ملفات CSS وJavaScript المحلية.
