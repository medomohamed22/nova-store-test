# AiWay 3 — مساحة برمجة بالذكاء الاصطناعي

نسخة مطوّرة تشمل محرر CodeMirror، معاينة متعددة الملفات مع React وTSX، مراجعة تعديلات جميع المزودين، رفع GitHub مع مراجعة الملفات، ZIP ونسخ احتياطية، وضع داكن واتصال تلقائي.

ابدأ بقراءة [دليل التشغيل العربي](دليل-التشغيل.md).

```sh
npm ci
npm run build
npm run dev
```

افتح `http://localhost:4173`. مطلوب Node.js 22 أو أحدث. ملفات بناء الواجهة مرفقة في `assets` والكود في `src`، وإعداد Vercel موجود في `vercel.json`.

نتائج الاختبارات وحدود التحقق في [VALIDATION.md](VALIDATION.md). لقطات الواجهة في `preview`.
