# AiWay 3.2 — مساحة برمجة بالذكاء الاصطناعي

نسخة مطوّرة تشمل محرر CodeMirror، معاينة React وTSX، مراجعة تعديلات جميع المزودين، GitHub وZIP ونسخ احتياطية. الإصدار 3.1 يصلح انتظار تسجيل ChatGPT، ويضيف قوالب مهام ولوحة سياق وتعديلات واختبارات ومراجعة مستوحاة من [Zadloop](https://zadloop.com/)، مع تشغيل اختبارات JavaScript فعلية على المشروع أو التعديلات المقترحة، وتبديل لغة التنقل.

ابدأ بقراءة [دليل التشغيل العربي](دليل-التشغيل.md).

الإصدار 3.2 يضيف [10 قدرات مستوحاة من Hermes Agent](مميزات-Hermes.md): ذاكرة بنطاق عام أو مشروع، مهارات SKILL.md، بحث نص المحادثات، تعليمات المشروع، مراجع @، شخصيات، خطة مهام، مزود API احتياطي، قراءة صوتية، وتصدير محادثة JSON/Markdown. افتح «قدرات الوكيل» من القائمة أو تبويب «الوكيل».

```sh
npm ci
npm run build
npm run dev
```

افتح `http://localhost:4173`. استخدم Node.js 22.x. ملفات بناء الواجهة مرفقة في `public/assets` والكود في `src`، وإعداد Vercel موجود في `vercel.json`.

لتسجيل ChatGPT: فعّل Device Code في إعدادات أمان حسابك، ثم افتح الإعدادات في AiWay واطلب كود الدخول. على Vercel يجب تفعيل Fluid compute لدعم WebSocket. خطوات الربط والاحتفاظ بتسجيل الدخول موجودة في الدليل العربي.

نتائج الاختبارات وحدود التحقق في [VALIDATION.md](VALIDATION.md). لقطات الواجهة في `preview`.
